# In-app Help (MDX)

These MDX articles are rendered inside the product under **Help** (`/help`).

| File | Route |
| --- | --- |
| `user-guide.mdx` | `/help/user-guide` |
| `design.mdx` | `/help/design` |
| `development.mdx` | `/help/development` |

Frontmatter fields: `title`, `summary`, `audience`, `order`.

Engineering ADRs and phase docs remain elsewhere under `docs/`; do not move them here.
